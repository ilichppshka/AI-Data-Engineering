# Данные курса

Здесь живут все данные проекта. **В репозиторий они не коммитятся** — каждый
получает их сам (см. `README.md`, раздел «Данные»).

## Слои

| Папка | Что внутри | Кто создаёт | Можно ли менять руками |
|-------|------------|-------------|------------------------|
| `raw/olist/` | исходные CSV «как приехали» | `src/get_data.py` | **нет, никогда** |
| `staging/parquet/` | те же данные в Parquet | ЛР 2 | пересоздаётся из raw |
| `staging/clean/` | слой CLEAN: типы приведены, правила проверены | ЛР 3 | пересоздаётся |
| `processed/warehouse.duckdb` | хранилище: схемы `main`, `core`, `mart` | ЛР 2–5 | пересоздаётся |
| `marts/` | витрины и таблица признаков (Parquet) | ЛР 4–6 | пересоздаётся |
| `quality/` | отчёты о качестве и карантин отбракованных строк | ЛР 3 | читать, не править |
| `_runs/` | метаданные запусков pipeline и результаты проверок | ЛР 5, `checks/` | служебное |
| `sample/` | маленький срез данных для технических тестов | `get_data.make_sample()` | — |

## Принцип RAW

Слой `raw/` неизменяем. Любая ошибка в обработке чинится **пересчётом из raw**,
а не правкой файлов. Если вы отредактировали что-то в `raw/` — воспроизводимость
курса потеряна; удалите папку и загрузите данные заново.

## Сброс состояния

Полностью пересобрать всё, кроме сырых данных:

```bash
rm -rf data/staging data/processed data/marts data/quality data/_runs logs
python -c "import sys; sys.path.insert(0,'src'); import paths; paths.ensure_dirs()"
```

Затем выполнить лабораторные по порядку.
