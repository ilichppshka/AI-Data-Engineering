# Кейс 3. Сеть медицинских лабораторий

Результаты анализов приходят с 12 приборов разных производителей: у одних CSV,
у других XML, у третьих JSON через локальный API, выгрузка раз в час.
Врачи видят результаты в личном кабинете пациента; раз в сутки считается
статистика по загрузке лабораторий.

Особенности: разные единицы измерения; повторные выгрузки с уточнённым
результатом; ошибка в данных = неверный медицинский результат у человека;
производитель может обновить прошивку и поменять формат.

> Разбор преподавателя: `solutions/03_etl_quality_solution.ipynb`, раздел
> «Разбор кейса 3».
