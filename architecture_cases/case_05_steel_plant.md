# Кейс 5. Металлургический завод

Прокатный стан, ~2000 сигналов с датчиков, каждый пишется раз в секунду.
Локальный сервер цеха раз в 15 минут выгружает данные в корпоративную сеть.

Потребители: оператор у стана (алерты за пару секунд), технологи (суточные
отчёты по браку), инженеры по надёжности (история за 3 года), модель
предсказания отказа подшипника (переобучение раз в месяц).

Особенности: связь с дата-центром пропадает на часы, данные приезжают пачкой
задним числом; время на датчиках иногда «уплывает».
