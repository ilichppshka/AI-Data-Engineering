# Кейс 2. Городская библиотечная сеть

40 филиалов. Каждую ночь каждый филиал выгружает CSV с выдачами и возвратами
за день: суммарно ~40 МБ в сутки, ~300 тысяч строк.

Нужно: ежемесячный отчёт в мэрию; поиск по карточке читателя для библиотекаря
(«что у него на руках сейчас»); хранение истории за 10 лет.

Коллега предлагает: «Kafka для сбора выгрузок, Spark для обработки,
ClickHouse для отчётов». Оцените это предложение.

> Разбор преподавателя: `solutions/02_storage_sql_solution.ipynb`, раздел
> «Разбор кейса 2».
