# Кейс 4. Банк среднего размера

Источники: АБС с операциями по счетам (PostgreSQL), система заявок на кредиты,
события мобильного приложения, данные бюро кредитных историй через API.

Потребители: регуляторная отчётность (раз в месяц, копейка в копейку,
воспроизводимость через три года); риск-аналитика (витрины по просрочкам,
раз в сутки); скоринг в момент выдачи кредита (ответ за секунды).

> Разбор преподавателя: `solutions/04_dwh_modeling_solution.ipynb`, раздел
> «Разбор кейса 4».
