# С чего начать

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Дальше откройте `notebooks/00_course_map.ipynb` и идите по номерам:
00 - 01 - 02 - 03 - 04 - 05 - 06.

Порядок обязателен: работы передают друг другу файлы в папке `data`.
Если открыть четвёртую, не выполнив третью, тетрадь скажет, чего не хватает.

Данные скачиваются сами при первом запуске. Интернета нет – курс возьмёт
офлайн-набор той же структуры, делать ничего не нужно.

Посмотреть, что уже зачтено:

```bash
python course_check.py
```
