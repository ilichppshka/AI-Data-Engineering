# С чего начать

Нужен Python 3.10 или новее.

Установите зависимости из папки проекта.

**macOS — Терминал:**

```bash
bash setup.sh
```

**Windows — PowerShell или командная строка:**

```powershell
.\setup.bat
```

Скрипт создаст `.venv` и установит основные зависимости через
[зеркало GitVerse](https://pypi-mirror.gitverse.ru/simple/). Повторный запуск использует
существующее окружение. `.venv` не нужно переносить между компьютерами или
добавлять в Git — на каждом компьютере она создаётся заново.

Зеркало сохраняется в настройках pip внутри `.venv`, поэтому последующая
доустановка пакетов из этого окружения тоже использует его. Чтобы выбрать
другой источник, задайте переменную `PIP_INDEX_URL` перед запуском скрипта.

Для дополнительных пакетов из `requirements-optional.txt` (JupyterLab и
Kaggle) добавьте `--optional`: `bash setup.sh --optional` на macOS или
`.\setup.bat --optional` на Windows.

В VS Code выберите ядро ноутбука из созданной `.venv`:
`.venv/bin/python` на macOS или `.venv\Scripts\python.exe` на Windows.

Для запуска команд курса в терминале активируйте окружение.

**macOS:**

```bash
source .venv/bin/activate
```

**Windows — PowerShell:**

```powershell
.\.venv\Scripts\Activate.ps1
```

**Windows — командная строка (cmd):**

```bat
.venv\Scripts\activate.bat
```

Дальше откройте `notebooks/00_course_map.ipynb` и идите по номерам:
00 - 01 - 02 - 03 - 04 - 05 - 06.

Порядок обязателен: работы передают друг другу файлы в папке `data`.
Если открыть четвёртую, не выполнив третью, тетрадь скажет, чего не хватает.

Данные скачиваются сами при первом запуске. Интернета нет – курс возьмёт
офлайн-набор той же структуры, делать ничего не нужно.

Посмотреть, что уже зачтено:

```bash
python course_check.py
```
